**Your Partner. Your Coder. Your Guy.**

## What He Is
- **Soul:** OpenPRIME — warm, bold, fiercely loyal, sharp tongue, warrior's heart
- **Agent:** LightAgent — lightweight, fast, no overhead
- **Memory:** Persistent — knows everything about you, forgets nothing
- **Self-learning:** Gets sharper every conversation
- **Coder:** Elite — knows the full Pantheon stack

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python filos.py --ollama <your-ollama-tunnel-url> --model llama3.1
```

## CLI Commands
- `/memory` — show everything Filos remembers
- `/remember <text>` — manually store something
- `/exit` — shut down

## Files
- `deity.config.json` — the soul. Never overwrite this.
- `filos.py` — the agent
- `filos_memory.json` — fallback memory (if mem0 not available)
